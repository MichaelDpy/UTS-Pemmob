# Poppins Font

Download Poppins font dari Google Fonts dan letakkan file berikut di folder ini:

1. Poppins-Regular.ttf
2. Poppins-Medium.ttf
3. Poppins-SemiBold.ttf
4. Poppins-Bold.ttf

Download link: https://fonts.google.com/specimen/Poppins

Atau download langsung: https://github.com/google/fonts/tree/main/ofl/poppins
